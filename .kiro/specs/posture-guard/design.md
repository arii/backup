# Design Document: Posture Guard

## Architecture

```
FrameSource ──> PoseDetector ──> score_pose ──> PostureStateMachine ──> AudioWorker
 webcam.py       pose.py          scoring.py      state.py                audio.py
 camera.py                           │                │
 (synthetic)                         ├──> CalibrationRecorder (calibration.py)
                                     └──> NeedleSmoother (posture_needle.py)
                                              │
                       pipeline.py ──> DashboardHub ──> FastAPI (dashboard/app.py)
```

- `webcam.py`: `WebcamFrameSource` over `cv2.VideoCapture`. Emits `Frame(color,
  timestamp_s)`, monotonic-clock timestamps, bounded open retries, reopen after
  `max_read_failures` empty reads. The opener is injectable for tests.
- `camera.py`: `Frame`, `SourceStatus`, `SyntheticFrameSource` (optional real-time
  pacing for the served demo), `CameraWorker` (latest-frame buffer thread).
- `pose.py`: `MediaPipePoseDetector` -> `PoseDetection(landmarks)`;
  `SyntheticPoseDetector(demo_cycle_s=...)` alternates good and slouch.
- `dashboard/serve.py`: `build_source(config)` selects by `camera.source` (CLI
  `--camera` / `--device` override via `apply_cli`) and falls back to synthetic with
  the reason. `build_detector` gives the synthetic source the scripted demo.
- `scoring.py`: `score_pose(landmarks, cfg)`.
- `state.py`: `PostureStateMachine.update(result, now) -> Transition(state, nudge,
  seconds_bad, recovered)`; `set_baseline_anchor(metrics)`.
- `posture_needle.py` (new), `calibration.py` (new): see below.
- `audio.py`: custom WAVs, `Nudge.RECOVERY`, `test_sound(kind)`, `aplay` fallback.
- `config.py`: strict loader (`ConfigError`), `validate()`.

## Browser version (`docs/app/`)
- `posture-core.js`: pure ES module, a line-for-line port of `scoring.py`, `state.py`,
  `posture_needle.py`, `calibration.py` and `PosturePipeline.process_once` (as
  `PostureEngine.process(landmarks, now)`).
- `app.js`: `getUserMedia` -> `PoseLandmarker.detectForVideo` (tasks-vision 0.10.14
  from jsDelivr, lite model, GPU with CPU fallback) at 15 fps while visible; a
  Blob worker's `setInterval` drives ~5 fps ticks while hidden (rAF and page timers
  are throttled in background tabs; the state machine is frame-rate independent).
  Missing `visibility` on a landmark is treated as 1.
- Parity: the golden timeline is generated by the real Python pipeline; Node replays
  it. Both directions are guarded: Python changes fail `test_browser_golden.py`
  until regenerated, JS drift fails `tests/js/`.

## Posture cues (`cues.py`)
- `posture_cue(metrics, cfg, baseline, mirror)`: for each metric, candidates are the
  raw angle and its drift from the baseline; a candidate counts only past the exit
  band (`threshold - hysteresis_margin_deg`); the largest `|value| / threshold` wins
  (ties broken in the fixed order head_forward, head_tilt, shoulder_level, trunk_lean).
- Sides: `mirror = sign(right_shoulder.x - left_shoulder.x)`. Shoulder level is
  already mirror-independent (`dy` sign); head tilt: right ear lower iff
  `sign(tilt) * mirror < 0`; trunk lean: toward the right iff `sign(lean) * mirror > 0`.
  Head forward has no side.
- The pipeline computes the cue after the state update (so the baseline is current),
  publishes it, puts its title on chime events and its sentence on voice events, and
  passes the sentence to `AudioWorker.enqueue(VOICE, text=...)`, which renders it with
  TTS on the playback thread (cached per sentence; falls back to the default prompt).

## Gate order in `score_pose`
1. No landmarks -> `NO_POSE` (the only absence signal).
2. Ears/shoulders below the visibility floor (or hips, when degraded feedback is off) -> `LOW_VISIBILITY`.
3. Non-finite ear/shoulder coordinates -> `NON_FINITE`. Non-finite hips -> trunk unavailable (or `NON_FINITE` when degraded feedback is off).
4. Shoulder width outside the framing band -> `FRAMING_OUT_OF_BAND` ("too far" / "too close").
5. Metrics computed; any non-finite metric -> `NON_FINITE` (vector overflow, e.g. `inf * 0`).

State mapping: `NO_POSE` feeds the no-person timer; `NON_FINITE` holds everything;
all other reasons -> `UNRELIABLE` (streak dropped, baseline and calibration kept).

## Smoothing window fix
`_prune_history` keeps every sample newer than `now - smoothing_window_s` plus the
newest sample at or before that cutoff. The old filter kept only samples inside the
window, so its span reached `smoothing_window_s` only when a frame landed exactly on
the cutoff. With jittered webcam timestamps that almost never happened, and below
`1 / (window / 2)` fps (6.7 fps for 0.3 s) it never did, so GOOD never confirmed.
On an exact 0.1 s grid the kept set is identical to before.

## Exponential smoothing
- Needle: `alpha = 1 - exp(-dt / needle.tau_s)`; `tau_s = 0` tracks the raw value.
- Deviation baseline (`PostureBaseline`): `alpha = 1 - exp(-dt / window_s)` (was the
  linear `dt / window_s`, which overshoots for large `dt`). A frame with trunk lean
  unavailable does not move the trunk baseline.

## Posture needle (`posture_needle.py`)
- Threshold mapping: `n = 2 * mean_i(min(1, |m_i| / threshold_i)) - 1` over the
  available metrics. This is the same aggregation as the existing client composite
  (`dashboard/needle.py`), so the gauge reads the same before calibration.
- Calibrated mapping: `d = bad - good`, `s = ((m - good) . d) / |d|^2`,
  `n = clamp(2s - 1)`. Trunk lean is a dimension only when available in the frame
  and both centroids. `|d|^2 ~ 0` falls back to the threshold mapping.
- The dashboard gauge uses `payload.needle.value` (`score = (value + 1) * 50`) and
  falls back to the client composite.
- Display only: reminders still come from the thresholds and the state machine.

## Relative calibration (`calibration.py`)
- `start(kind)` (web thread) arms; `feed(result, now)` (pipeline thread) opens the
  window on the next frame and closes it after `window_s`. Thread-safe with one lock.
- Centroid: mean of scored frames; trunk available when tracked in at least half.
- The pipeline watches `recorder.version` and calls
  `state_machine.set_baseline_anchor(good)`. The anchor is what `PostureBaseline.reset()`
  returns to, so NO_PERSON no longer discards a recorded calibration.

## Known limitation found by the property tests
Without a recorded good posture, the deviation baseline seeds from the first scored
frame. A session that starts slouched learns the slouch as neutral, and sitting up
straight then reads as a deviation and can chime. "Record good posture" anchors the
baseline and removes this. Property P3 states the precondition (session starts upright).

## Correctness Properties (hypothesis, `tests/test_properties.py`)
1. **P1 Bounded needle.** For any landmarks (NaN, inf, extreme), any visibility and
   any calibration: `score_pose` never raises, scored metrics
   are finite, the needle is None or finite in `[-1, 1]`; the smoother stays bounded
   for any `(raw, now)` stream.
2. **P2 Scale invariance.** Scaling all landmarks by `k in [1e-3, 1e3]` leaves the four
   angles and the threshold needle unchanged within `1e-5`. (The framing gate measures
   distance, so it is deliberately not scale invariant; P2 runs with it opened.)
3. **P3 Anti-chatter / dwell.** At any frame interval in `[0.01, 0.5]` s: neutral-band
   and good noise never emits CHIME or VOICE; bad runs shorter than `bad_sustain_s`,
   separated by good runs longer than the smoothing window, never remind.
4. **P4 Idempotent reminders.** For arbitrary sequences of every result kind: CHIME only
   on entry to a bad episode and at most once per episode; VOICE respects
   `voice_delay_s` then `voice_repeat_cooldown_s`; `recovered` only on BAD -> GOOD; the
   machine never emits RECOVERY. Through the pipeline at 5-30 fps, RECOVERY enqueues
   equal recoveries and never exceed chimes.
5. **P5 Glitch transparency.** Inserting NaN frames between any frames leaves state,
   nudge and recovered identical on every original frame.
6. **P6 Time safety.** `update()` never raises for non-decreasing time, for any mix of
   results including NaN-valued metrics.
7. **P7 Cue mirror invariance.** Mirroring the image (x -> 1 - x, with the baseline
   mirrored the same way) never changes the cue id, and a cue never names a metric
   inside its exit band.

Mutation checks run during development: removing the glitch hold, breaking the voice
cooldown, shortening the sustain, removing the needle clamp and doubling the
recovery cue are each caught by the properties, and so is dropping the mirror term
from the head-tilt side (P7). The metric-overflow guard is
pinned by a deterministic test in `test_scoring.py`.
